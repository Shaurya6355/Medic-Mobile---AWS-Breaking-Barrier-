- Committed generated output is about 3.4 MB in compile-demo/output (screenshots 2,337 KB, preview build 805 KB, rest 302 KB) plus 91 KB in pipeline-demo/output. This is nearly the whole area; the real code (src/compiler 84 KB, scripts 20 KB, demo scripts) is small and clean.

Everything in output/ is regenerated by `compile:demo`, `compile:preview`, `compile:screenshots`, `compile:verify`, `pipeline:demo`.
- Safe to untrack and gitignore about 3.4 MB (compile-demo/output) and about 91 KB (pipeline-demo/output) if the owner accepts that reviewers must run the npm scripts to see them. Lockfiles for the demo tools are 260 KB and are legitimate (pinned toolchain), keep.
