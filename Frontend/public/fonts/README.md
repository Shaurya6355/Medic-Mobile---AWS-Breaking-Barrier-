# Clarika Geometric

Clarika Geometric is a commercial font, so it is not in this repo. Put your licensed web font files here with
these names (WOFF2):

- `ClarikaGeometric-Regular.woff2` (400)
- `ClarikaGeometric-Medium.woff2` (500)
- `ClarikaGeometric-Bold.woff2` (700)

`src/fonts.css` loads them. A copy installed on your computer is used first. Until the files are here, the app
shows Jost (Google Fonts), a free geometric sans that is close in shape.
